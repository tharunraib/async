# ASYNC'26 demo flow

1. Turn Wi-Fi off and show the egress meter.
2. Ingest a fresh incident.
3. Show its failure fingerprint.
4. Detect a recurrence cluster containing historical incidents.
5. Inspect evidence supporting the hypothesis.
6. Show a previous remediation outcome.
7. Open a proposed change.
8. Run pre-flight and show the recurrence warning.
9. Demonstrate policy-gated action handling.
10. Show the audit chain.

Only report metrics as measured after running the final build.
